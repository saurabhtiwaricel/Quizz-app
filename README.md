# Overview

This is a simple multiple-choice Quiz App built using Swift and UIKit. The app allows users to answer a series of questions, tracks their score, and displays the results in a table view. Users can review their answers, see the correct ones, and restart the quiz.

# Features

- Display multiple-choice questions with four options.

- Track user responses and update the score.

- Navigate to a results screen showing the final score and answers.

- Use a table view to list all questions, correct answers, and user-selected answers.

- Restart the quiz with a reset button.
